# myfin-map

Веб-приложение для визуализации курсов валют в банках и обменных пунктах с привязкой к карте. Проект собирает данные с сайта myfin.by, сохраняет их в SQLite и отображает наиболее выгодные курсы покупки/продажи валют на интерактивной карте.

## Что это за проект

`myfin-map` — это сервис, который позволяет:

- мониторить курсы валют по отделениям банков;
- искать точки с наиболее выгодным курсом покупки/продажи;
- показывать распределение курсов на карте Беларуси;
- обновлять данные по выбранной валюте через API;
- работать как локальный веб-сервис на Flask.

Основной стек:

- Python
- Flask
- SQLAlchemy
- Folium
- Pandas
- Selenium

## Основные возможности

### 1. Карта курсов валют

На странице строится интерактивная карта с:

- тепловой картой по банкам;
- маркерами лучших курсов покупки и продажи;
- clustering маркеров для удобного отображения;
- выбором валюты (USD, EUR, RUB).

### 2. Парсинг данных

Проект загружает данные по курсам валют для банков и обменных пунктов с сайта `myfin.by` и сохраняет их в локальную базу данных.

### 3. Автообновление данных

Перед загрузкой карты система проверяет дату обновления и, при необходимости, обновляет данные через парсер.

### 4. API endpoints

Приложение предоставляет след��ющие основные ручки:

- `POST /api/parse` — запускает парсинг данных для выбранной валюты;
- `POST /api/map` — строит HTML карты для выбранной валюты;
- `/dashboard` — основная страница с картой.

## Требования

Перед запуском убедитесь, что у вас установлены:

- Python 3.10+
- pip
- браузер для просмотра карты

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/LittleAngel4ever/myfin-map.git
cd myfin-map
```

2. Создайте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
# .venv\Scripts\activate   # Windows
```

3. Установите зависимости:

```bash
pip install -r project/requirements.txt
```

## Запуск

Запустите приложение из корня проекта:

```bash
python project/app.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:5000/dashboard
```

## Примечания по работе

- Данные сохраняются в папку `project/instance/` внутри базы SQLite.
- Для корректной работы могут потребоваться актуальные зависимости и доступ к интернету при первом парсинге.
- В проекте используется локальный кеш данных через `data_damp.txt`.
